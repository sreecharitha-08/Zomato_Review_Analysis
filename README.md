# Zomato_Review_Analysis
📌 Project Overview – ZRA Sentiment Analysis App

A simple Flask-based machine learning web application that predicts whether a customer review is positive or negative. The project integrates a trained Naive Bayes model with TF-IDF vectorization to deliver real-time sentiment analysis through a clean web interface.

⚙️ Key Features

Web Interface: User-friendly text input for instant predictions

ML Model: Pretrained Naive Bayes classifier with TF-IDF features

Training Script: Includes dataset processing and model saving

Lightweight Deployment: Easily runs on local systems or cloud platforms

🧠 Tech Stack

Python, Flask

Scikit-learn (Naive Bayes, TF-IDF)

Pandas, NumPy

Pickle for model loading
